# Interactive Vehicle Market Dashboard (Python & Streamlit)

### 1. Project Objective
The primary objective of this project is to build an interactive web-based data application to analyze and visualize a vehicle marketplace dataset. The goal is to empower business stakeholders, sales operations teams, and consumers to filter car advertisements dynamically, understand pricing distributions, and identify the core factors (such as odometer mileage and vehicle condition) that affect a vehicle's market value.

### 2. Results & Business Impact
- Developed a fully functioning, cloud-deployed Streamlit web application that removes the need for manual Excel reporting.
- Engineered interactive exploratory charts (Histograms and Scatter Plots) with dynamic checkbox filters, enabling instant identification of market anomalies and automotive pricing trends.
- Delivered an intuitive tool that optimizes inventory evaluation and sales pricing strategies based on actual historical marketplace data.

### 3. Tools & Technologies Used
- **Programming Language:** Python
- **Data Manipulation:** Pandas
- **Data Visualization:** Plotly Express
- **Application Framework:** Streamlit
- **Environment & Version Control:** Git, GitHub

### 4. Key Learnings & Competencies Acquired
- **Exploratory Data Analysis (EDA):** Mastered data cleaning techniques, handling missing variables, and data type transformations using Pandas.
- **Interactive Web Deployment:** Learned how to transform static data analysis scripts into reactive, user-facing dashboards using Streamlit components.
- **Data-Driven Storytelling:** Enhanced capabilities in configuring targeted visualization charts (scatter plots and distributions) to answer precise commercial hypotheses.

### 5. Future Improvements
- Implement a machine learning predictive model (using Scikit-learn) to allow users to predict a car's price automatically based on inputs like year, model, and mileage.
- Optimize database integration by migrating the source CSV file into a relational SQL database structure to support larger data volumes.

---
### 🚀 How to Run this Application Locally
1. Clone the repository: `git clone https://github.com`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the Streamlit app: `streamlit run app.py`
